## About Coevo

Coevo supports a learning workflow built around real conversations. It identifies useful concepts from dialogue and turns them into flashcards, giving learners a practical way to transform passive discussion into structured review material.

Review sessions use the FSRS spaced repetition algorithm to help organize recall over time. Coevo also includes objective verification steps intended to assess whether a concept has been understood and internalized rather than merely recognized.

---

## Features

- Generate flashcards from learning conversations with AI assistance
- Extract important concepts from dialogue
- Schedule reviews with FSRS spaced repetition
- Use structured recall to reinforce learning over time
- Verify learning through objective internalization checks
- Combine Rust backend capabilities with a Flutter application layer
- Provide a cross-platform foundation for ongoing study workflows
